Execution Flow

How It Works

A direct, four-step path from problem exploration to shipped code and technical storytelling.

1

Pick a Track

Choose one of the 3 real-world problem statements tailored to developer tools, digital media, or public access.

2

Build with IBM Bob

Use IBM Bob as your primary AI pair-programmer to design logic, write features, and troubleshoot hurdles rapidly.

3

Deploy on GitHub

Ship a clean public repository equipped with architecture notes and a detailed, reproducible README.md.

4

Publish a Blog

Write and post your project build story, learnings, and Bob prompt snippets directly on the IBM Community portal.

Critical Rule: Your project counts as complete only when the GitHub repo and the community blog are both published and live before the 1:30 PM cutoff!
